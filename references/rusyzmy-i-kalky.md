# Русизми, кальки і штампи: повний словник

Довідник до розділу «Чистота мови» в SKILL.md. Відкривай, коли текст довгий або мовних помилок багато.

Як користуватися: шукай у тексті слово з лівої колонки і заміни відповідником із правої з урахуванням контексту. Якщо автор свідомо пише розмовно (суржик як прийом, цитата чужої мови), не виправляй.

## Прикметники, займенники, дієприкметники

| Неправильно | Правильно |
|---|---|
| даний (метод, випадок) | цей |
| слідуючий | наступний |
| наступні (у значенні «такі») | такі: «маємо такі переваги» |
| самий кращий, самий великий | найкращий, найбільший |
| любий (у значенні «будь-який») | будь-який |
| вірний (у значенні «правильний») | правильний; «вірний» = відданий |
| ведучий (спеціаліст) | провідний (фахівець) |
| виключення, виключно | виняток, винятково, лише |
| міроприємство | захід |
| працюючий | який працює; працівник |
| оточуючі | люди довкола, інші |
| оточуюче середовище | довкілля |
| бажаючі | охочі |
| діючий (закон, версія) | чинний |
| відпочиваючі | відпочивальники, ті, хто відпочиває |
| завідуючий | завідувач |
| вражаючий | вражальний, разючий, або конкретно: чим саме вражає |

Загальне правило: активні дієприкметники на -учий/-ючий/-ачий/-ячий для української нетипові. Заміни підрядним реченням («яка працює»), іменником («працівник») або прикметником («чинний»). Усталені винятки трапляються («сидячий режим», «лежачий хворий»), але в маркетингових текстах їх майже немає.

## Кальки з англійської, типові для ШІ

| Калька | По-людськи |
|---|---|
| робить сенс | має сенс |
| на щоденній основі | щодня |
| на регулярній основі | регулярно |
| в кінці дня | зрештою, у підсумку |
| бути в змозі | могти |
| адресувати проблему | взятися за проблему, розв'язати |
| зробити різницю | вплинути, змінити |
| давайте зануримося, глибоке занурення | розберімося; детально |
| змінює правила гри | назви, що саме змінюється |
| розблокувати потенціал | назви, що людина зможе |
| навігувати (складнощі) | долати, розбиратися |
| ландшафт (ринку, технологій) | ринок, ситуація |
| подорож (у значенні «шлях клієнта», «journey») | шлях, процес, або прямо: «від першого повідомлення до покупки» |
| екосистема (абстрактно) | пряма назва: сервіси, спільнота, набір інструментів |
| простір (безпечний простір, простір для росту) | конкретно, про що йдеться |
| інсайти (як порожня оцінка) | висновки, ідеї, або сам висновок |
| оптимізувати процеси | назви, що саме стане швидше або дешевше |

Якщо англіцизм - частина голосу автора («скіл», «пайплайн», «засейвитись»), він лишається. Калька - це запозичена конструкція, а не слово.

- У наш час...
- В епоху цифровізації / штучного інтелекту...
- Сьогодні як ніколи...
- У світі, що стрімко змінюється...
- Ні для кого не секрет, що... / Не секрет, що...
- Уявіть собі...
- Давайте розберемося / Давайте зануримося...

### Переходи
- Варто зазначити, що...
- Важливо підкреслити, що...
- Слід зауважити...
- Не можна не згадати...
- Окремо варто виділити...

- Таким чином, / Отже, підсумуємо...
- Насамкінець...

### Роздування
- відіграє ключову роль
- є невід'ємною частиною
- відкриває нові можливості / безмежні можливості
- виводить на новий рівень
- змінює правила гри
- знаменує собою новий етап
- залишає незгладимий слід
- справжня магія
- ідеальне рішення для
- комплексний / індивідуальний підхід
- секрет успіху
- інвестиція в себе
- вийти із зони комфорту
- розкрити свій потенціал

## Граматика і правопис

- **Кличний відмінок у зверненнях:** Олено, Юлю, Андрію, Тетяно, пане Іване, друзі, колеги. Не «Привіт, Олена!».
- **«Ви» з великої літери** - лише у листі до однієї конкретної людини, з повагою. У постах, розсилках, на сайті, в описах продуктів - «ви».
- **Милозвучність:** у/в, і/й, з/із/зі чергуються залежно від сусідніх звуків: «вона в Україні», «він у Києві», «ти й вона», «брат і сестра», «зі школи», «із собою».
- **Апостроф:** після б, п, в, м, ф, р перед я, ю, є, ї - «м'ята», «п'ять», «ім'я», «пір'я». Один і той самий символ (' або ʼ) у всьому тексті.
- **Лапки:** «ялинки»; лапки всередині лапок - „лапки“.
- **Тире:** коротке « - » з пробілами замість довгого «—» (стиль цього скіла).
