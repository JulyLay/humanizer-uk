# humanizer-uk - скіл для Claude Code

**редактор українських текстів: прибирає ознаки ШІ, канцелярит і русизми, не вигадуючи фактів**

Вставляєш текст, який писала нейронка, і отримуєш живий текст українською. Цифри, імена, посилання і твій стиль лишаються на місці.

## ✍️ Що вміє

- Прибирає довгі тире: у відповіді не буде жодного «—», лише коротке «-».
- Прибирає ШІ-штампи: «У сучасному світі», «Варто зазначити», «відіграє ключову роль», «не просто X, а Y», «Чому це важливо? Бо...», «Майбутнє вже тут».
- Чистить мову: русизми («являється», «на протязі», «в якості»), кальки з англійської («на щоденній основі», «робить сенс»), кличний відмінок у зверненнях, «Ви» з великої лише там, де треба.
- Прибирає канцелярит, воду, пасив і правило трьох.
- Не вигадує. Де тексту бракує конкретики, ставить мітку `[конкретика: ...]` і пояснює, що дописати, а не придумує цифри від твого імені.
- Береже голос автора: сленг, англіцизми, авторські емодзі, кодові слова для ботів і CTA лишаються.

## 👀 Приклад

**До:**
> У сучасному світі штучний інтелект відіграє ключову роль у розвитку бізнесу. Варто зазначити, що 73% підприємців вже використовують ШІ на щоденній основі. Це не просто тренд — це нова реальність.

**Після:**
> 73% підприємців уже щодня працюють із ШІ. Інші поки що обходяться без нього.

## 🚀 Як встановити

Відкрий Claude Code, новий чат, встав промт:

```
Встанови мені скіл з репозиторію https://github.com/JulyLay/humanizer-uk.git так, щоб він був доступний у будь-якому чаті назавжди:
1. Зклонуй репозиторій у ~/.claude/skills/humanizer-uk (якщо папки ~/.claude/skills немає - створи).
2. Видали з неї папку .git.
3. Перевір, що є файл ~/.claude/skills/humanizer-uk/SKILL.md.
4. Зроби все сам і коротко підтверди, що скіл встановлено.
```

Або командою в терміналі:

```bash
git clone https://github.com/JulyLay/humanizer-uk.git ~/.claude/skills/humanizer-uk && rm -rf ~/.claude/skills/humanizer-uk/.git
```

Далі просто напиши в чаті «відредагуй, прибери ШІ» і встав текст, або виклич `/humanizer-uk`.
